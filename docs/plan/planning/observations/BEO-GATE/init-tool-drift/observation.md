# Das Init-Tool driftet mit dem Kurs

**Sub-Area:** Gate-/Werkzeug-Schicht

Der Bootstrap-Generator (`ai-harness-init`, seit `v6.13.0` Teil des Kurses)
erzeugt die kanonische Projektform und entwickelt sich mit jedem Kurs-Release
weiter (neue Features wie die Erfassungsschicht, geänderte Layouts). Der
Vergleich eines a-check-Bestands gegen eine Generator-Ausgabe ist darum
Snapshot-gebunden: ein Vergleich-Slice vergleicht den Zustand eines Tages.
