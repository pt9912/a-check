# Ein Testkommentar sagt mehr zu, als seine Assertion prüft

**Sub-Area:** Gate-/Werkzeug-Schicht

Der Kommentar über einem Test beschreibt eine Eigenschaft — „prüft Kommentar und Zeichenkette",
„zeigt auf die Zeile des Eintrags" —, die Fixture oder Assertion aber nicht abdecken. Der Test ist
grün, und wer den Kommentar liest, hält die Eigenschaft für belegt.
