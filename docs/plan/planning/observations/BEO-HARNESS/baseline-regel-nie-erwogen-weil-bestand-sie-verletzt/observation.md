# Eine Baseline-Regel wird nie erwogen, weil der Bestand sie durchgängig verletzt

**Sub-Area:** Harness-Einstieg

Steht eine Regel der vendorten Baseline im Widerspruch zur gewachsenen Praxis, wird sie beim
Arbeiten nicht als Regel wahrgenommen, sondern als Nicht-Thema: Jeder neue Fall folgt dem
Bestand, weil der Bestand *aussieht* wie die Konvention. Die Regel fällt nicht auf, wenn man sie
bricht — sie fällt auf, wenn jemand sie liest.

Das unterscheidet diese Klasse von einer bekannten Abweichung: Eine deklarierte Adaption ist
sichtbar, eine unerkannte Regel ist es nicht. Und sie unterscheidet sich von einem Sensor-Ausfall:
Es gibt keinen Sensor, der versagt hätte — die Regel betrifft eine **Form**, die kein Gate prüft.

Gegenmittel gibt es zwei, und beide sind teuer: die Baseline vollständig gegen den Bestand lesen
(der Adaptions-Durchgang tut das für Regeln, zu denen es bereits einen Eintrag gibt — für Regeln
**ohne** Eintrag tut es niemand), oder die Form maschinell prüfen, wo sie sich als Muster fassen
lässt.
