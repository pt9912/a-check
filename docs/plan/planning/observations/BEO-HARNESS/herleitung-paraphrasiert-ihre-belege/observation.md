# Die Herleitung einer Regel paraphrasiert ihre Belege, statt sie wiederzugeben

**Sub-Area:** Harness-Einstieg

Eine Regel wird mit gemessenen Fällen hergeleitet (Reviewer-Skill §Mess-Regeln). Die Fälle stehen
in Zitatzeichen, sind aber umformuliert, oder die Zusammenfassung ist enger oder gröber als der
Beleg, auf den sie zeigt. Wer die Herleitung liest, hält die Paraphrase für den Fund.
