# Nach einer Auslagerung bleibt die alte Verortung an Zeigerstellen stehen

**Sub-Area:** Harness-Einstieg

Ein Regeltext zieht aus einer Datei in eine eigene um; Stellen, die ihn **verorten** — „die Zusage
steht in `AGENTS.md` §5" in einem Skill, das Zielort-Feld eines Register-Eintrags —, nennen
weiter den alten Ort. Der Link löst auf (die Datei gibt es noch), nur der Inhalt steht dort nicht
mehr; kein Link-Sensor sieht das.
