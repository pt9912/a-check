# Eine Messung steht als Beleg da, ohne dass ihr Instrument im Repo liegt

**Sub-Area:** Planungs-Harness

Ein Slice-Plan oder eine Closure-Notiz stützt eine Aussage auf **Zahlen** — Kandidaten, Treffer,
Zeichen, Anteile. Die Zahlen sind echt gemessen, aber das **Instrument** ist ein Einweg-Aufruf, der
mit der Sitzung verschwindet: kein Skript im Repo, keine genannten Parameter, kein Korpus.

Damit ist der Beleg **nicht wiederholbar**, und das trifft ihn zweifach. Ein Leser kann ihn nicht
nachvollziehen — und der Schreibende selbst kann es beim nächsten Lauf nicht: Dieselbe Frage,
anders parametrisiert, liefert eine andere Zahl, und keine der beiden weiß von der anderen.

**Das unterscheidet die Klasse von einer bloßen Ungenauigkeit.** Die Zahl kann stimmen; sie ist
trotzdem kein Beleg, weil ihr die Bedingung fehlt, unter der sie gilt. **Und es unterscheidet sie
von [`review-geltungsbereich-zu-eng`](../review-geltungsbereich-zu-eng/observation.md):** Dort ist
der Geltungsbereich *genannt und zu eng*; hier ist er nicht genannt.

**Woran sie auffällt:** wenn jemand nachmisst und eine andere Zahl bekommt — oder wenn zwei
Stellen desselben Repos zwei Zahlen für dieselbe Messung führen.
