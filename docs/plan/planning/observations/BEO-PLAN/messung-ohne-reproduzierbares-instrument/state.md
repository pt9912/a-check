**Stand:** offen (2×)

Unterhalb der Schwelle. Das naheliegende Gegenmittel — *„jedes Mess-Skript kommt ins Repo"* — ist
teurer, als es aussieht: Die meisten dieser Läufe sind Wegwerf-Abfragen, und ein Verzeichnis voll
Einweg-Skripte altert schneller als die Zahlen, die es erklären soll.

Was billig trägt, ist die Mess-Regel, die das Repo bereits führt
([`AGENTS.md`](../../../../../../AGENTS.md) §5, *Geltungsbereich einer Messung*): **die Parameter
in den Satz**, nicht in ein Skript. *„fünf Treffer"* wird zu *„fünf Treffer bei 8-Wort-Fenstern
über `regelwerk/*.md`, normalisiert"* — damit ist die Zahl reproduzierbar, ohne dass ein Werkzeug
committet wird. Beide bisherigen Fälle wären davon gefangen worden.

Beim dritten Mal ist es eine Lücke. Der Ausgangs-Kandidat wäre dann keine neue Regel, sondern eine
**Durchsetzungs**-Frage: ob eine Zahl in einem Slice-Plan ohne nebenstehende Parameter überhaupt
als Beleg gelten darf.
