# Verweis auf wandernden Slice bricht

**Sub-Area:** Planungs-Harness
**Ehemals:** `BEO-008` (Tabellenform, bis slice-139)

Ein Verweis **auf** einen wandernden Slice bleibt ungeprüft und bricht, wenn dieser wandert — die Lifecycle-Invariante ist auf wandernde Quellen gerichtet, nicht auf Verweise auf sie
