**Stand:** verkörpert

**verkörpert** in `make slice-mv` (`tools/slice-mv.sh`, seit slice-118): der `git mv` zieht die Verweise selbst nach. Der Zähler bleibt stehen — die Beobachtung ist nicht falsch geworden, sie hat einen Ort bekommen. Ungedeckt bleibt, wer `git mv` von Hand fährt; der Unterschied ist, dass der richtige Weg jetzt **kürzer** ist als der falsche
