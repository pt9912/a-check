# Ein neuer Vertrag ist an genau einem Konsumenten belegt

**Sub-Area:** Spec-Straten

Eine neue Regelart wird aus dem Bedarf **eines** Adopters geschnitten. Der Vertrag kann an dessen
Datei überangepasst sein — Dialekt, Normalisierung, Befund-Form —, und ob er trägt, zeigt erst ein
zweiter Konsument.
