# Eine Vertragsänderung zieht das Handbuch nach, die READMEs nicht

**Sub-Area:** Benutzer-Doku

Ein Slice ändert einen öffentlichen Vertrag (Lastenheft) und trägt die Änderung ins
Benutzerhandbuch und den CHANGELOG — die READMEs, die dieselbe Aussage in Kurzform tragen,
bleiben auf dem alten Stand. Kein Gate vergleicht sie; auffällig wird es erst, wenn jemand vor
einem Release fragt, ob die Doku aktuell ist.
