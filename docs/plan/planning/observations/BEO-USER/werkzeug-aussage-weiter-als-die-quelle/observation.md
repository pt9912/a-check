# Eine Aussage über ein fremdes Werkzeug deckt sich nicht mit dessen Quelle

**Sub-Area:** Benutzer-Doku

Das Handbuch sagt, wie sich ein fremdes Werkzeug verhält (Docker Desktop, Colima, eine Registry):
was es standardmäßig tut, wie ein Befehl wirkt. Die Aussage stimmt für einen Fall und wird auf
alle verallgemeinert, oder eine Bedienanweisung lässt Vorbedingung und Nebenwirkung weg — oder die
Quelle ändert sich später, und der Text altert still. Ein Gate sieht das nicht: Links lösen auf,
der Satz liest sich plausibel.
