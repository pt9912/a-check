## HIGH

### R-1 — `stripComments` ist nicht string-literal-bewusst; ein `/*` im String verschluckt den Rest der Datei

- **Quelle:** Review-Lauf
- **Pfad:** [`internal/adapter/driven/extract/extract.go`](../../internal/adapter/driven/extract/extract.go) (`stripComments`)
- **Befund:** `stripComments` liest rohe Bytes ohne Kenntnis von Zeichenketten-Literalen. Jede
  Byte-Folge `/*` **in einem String** öffnet einen Phantom-Blockkommentar, der bis zum nächsten
  `*/` — oft weit entfernt oder bis Dateiende — konsumiert wird. Jeder Import, jeder
  `forbidden_constructs`-Treffer, jeder `constructs`-Treffer und jede Kotlin-Deklaration danach
  verschwindet **still**. Betroffen sind alle C-Syntax-Backends (Go, C++, Rust, Kotlin, Java, C#,
  TypeScript); Python ist über `prepSource` ausdrücklich ausgenommen — **gegen genau diesen
  Fehler**. Die `//`-Variante ist zeilen-lokal, aber real: ein Import mit `https://`-URL wird an
  `"https:` abgeschnitten und ganz verworfen.
- **verifizierbar:** ja — Fixture mit Glob-String und nachfolgendem Verstoß.
- **Verifikation (Maintainer-Agent): BESTÄTIGT, beide Richtungen.**
  ```text
  Go-Fixture, Verstoss core -> adapters NACH  var globs = []string{"/**"}
    mit dem String    -> gesamt: 0 Befund(e)                            EXIT=0
    ohne den String   -> core-impurity: Kern importiert …               EXIT=1
  TypeScript, tech-Regel auf "deno.land", Import im Kern
    mit    // in der URL -> gesamt: 0 Befund(e)                         EXIT=0
    ohne   // in der URL -> core-impurity                               EXIT=1
  ```
  **Zur Selbstbetroffenheit, ehrlich:** `extract.go` trägt in der `dirExcluded`-Zeile den String
  `"/**"`; bis zum nächsten `*/` werden beim Selbstscan rund 340 Zeilen geblankt. Der **reale**
  Schaden im Eigen-Repo ist gering — die Go-Importe stehen oberhalb, und a-check nutzt keinen
  `constructs`-Block. Geschwächt ist die **Dogfooding-Aussage**, nicht die Prüfung selbst.

## MEDIUM

### R-2 — Die Grenz-Diagnose (Klasse 2) meldet Zeilen, die sehr wohl auflösen

- **Quelle:** Review-Lauf
- **Pfad:** [`internal/hexagon/core/rules.go`](../../internal/hexagon/core/rules.go) (`HeuristicLimits`)
- **Befund:** Die Klasse-2-Schleife behauptet, ein `./`/`../`-Symbol unter einem Modus ≠ `relative`
  könne „kein Ziel-Glob treffen, unabhängig vom Baum-Inhalt". Das ist für ein einsegmentiges
  Glob-Präfix falsch: bei `layers: {core: ["core/**"]}` liefert `globPrefix` den Wert `core`, und
  `segIndex("../core/model.h", "core")` findet ihn auf einer Segment-Grenze — `targetLayer` löst
  auf, die Kante **wird** beurteilt. Relative Includes sind in C++ die Norm, der Fall trifft also
  breit; zusammen mit der Kappung bei zehn Zeilen können die Falschmeldungen echte Klasse-1-Funde
  aus der Liste verdrängen.
- **verifizierbar:** ja — verbotene Kante über einen `../`-Pfad.
- **Verifikation (Maintainer-Agent): BESTÄTIGT, im schärfsten Sinn.** Dieselbe Zeile erscheint
  gleichzeitig als Befund **und** als unbeurteilt:
  ```text
  core/model.cpp:1: core-impurity: Kern importiert ../adapters/db/x.h
  Hinweis: … core/model.cpp:1: relativer Pfad, den der Auflösungs-Modus "path" nicht auflöst
  ```
  Die Prämisse steht wörtlich in [ADR-0031](../plan/adr/0031-heuristik-grenzen-diagnose.md)
  (Entscheidung 5) und ist damit **falsch dokumentiert**, nicht nur falsch implementiert. Die ADR
  ist `Accepted` und immutabel — die Korrektur braucht eine Folge-ADR mit `Supersedes`.

### R-3 — `NewTech` akzeptiert ein leeres Substring-Muster, das nie feuern kann

- **Quelle:** Review-Lauf
- **Pfad:** [`internal/hexagon/core/rules.go`](../../internal/hexagon/core/rules.go) (`NewTech`)
- **Befund:** Die Leer-Muster-Prüfung greift nur bei `match: regex`. Ein Eintrag
  `tech: [{adapter: "adapters/x"}]` (Muster fehlt oder leer) passiert `decodeTechs`/`NewTech` und
  erzeugt eine `Tech`, deren Treffer-Bedingung `t.Pattern != "" && …` dauerhaft falsch ist: eine
  stumme, tote `tech-leak`-Regel bei Exit 0. `NewConstruct` weist genau das in **beiden**
  Match-Modi ab, `validateZones` den analogen Leer-Adapter — der `tech`-Pfad ist der Ausreißer.
- **verifizierbar:** ja — Config mit leerem `tech.pattern`.
- **Verifikation (Maintainer-Agent):** **noch nicht gemessen.** Die Klasse ist dieselbe, die
  [slice-086](../plan/planning/done/slice-086-forbidden-constructs-fail-closed.md) für
  `forbidden_constructs` geschlossen hat; dessen Lerneintrag benannte `adapter_sink` und `markers`
  als Kandidaten — der Review hat die tatsächlichen gefunden.

- **Pfad:** [`internal/cli/cli.go`](../../internal/cli/cli.go)

### R-5 — Eine Schicht mit leerer Glob-Liste wird angenommen und matcht nichts

- **Quelle:** Review-Lauf
- **Pfad:** [`internal/adapter/driven/config/config.go`](../../internal/adapter/driven/config/config.go) (`decodeLayer`)
- **Befund:** `core: []` und `core: [""]` passieren ohne Fehler. `matchSpecificity` matcht dann nie,
  `LayerOf` liefert für jede Datei `""`, und jede an die Schicht gebundene Regel ist stumm inert —
  bei Exit 0. Dieselbe Silent-Never-Match-Klasse, die `validateExclude`, `validateZones` und
  `validateForbidden` fail-closed abweisen; `layers` ist das verbliebene Loch.
- **verifizierbar:** ja. · **Verifikation:** noch nicht gemessen.

### R-6 — Der Go-Importblock endet vor dem Import auf der Schlusszeile

- **Quelle:** Review-Lauf
- **Pfad:** [`internal/adapter/driven/extract/extract.go`](../../internal/adapter/driven/extract/extract.go) (`goImports`)
- **Befund:** Die Blockende-Prüfung greift, **bevor** `goQuoted` versucht wird. Gültiges Go der Form
  `import (\n\t"fmt")` extrahiert `"fmt"` daher nicht — der Import ist für jede Regel unsichtbar.
  Nicht gofmt-konform, aber es scheitert grün statt laut.
- **verifizierbar:** ja. · **Verifikation:** noch nicht gemessen.

### R-7 — `globToRegexp` kompiliert bei jedem Aufruf neu

- **Quelle:** Review-Lauf
- **Pfad:** [`internal/hexagon/core/rules.go`](../../internal/hexagon/core/rules.go)
- **Befund:** `regexp.MustCompile` läuft je Aufruf; `matchesAny`/`matchSpecificity` rufen es einmal
  je Glob und Pfad. Ein Scan über N Dateien mit G Globs führt damit O(N·G) Regex-Kompilierungen
  aus, was auf großen Bäumen die Laufzeit dominiert. Ein Cache je `Model` beseitigt das ohne
  Semantik-Änderung.
- **verifizierbar:** ja (Messung). · **Verifikation:** noch nicht gemessen.
